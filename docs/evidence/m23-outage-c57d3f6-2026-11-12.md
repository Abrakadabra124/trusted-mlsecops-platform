## Audit boundary и восстановление

Controlled authorization/trust fixture вызывает настоящий `promotion.promote`
в конфигурации с реальными SQL и collector. Проверяется ровно один audit check,
его отказ `promotion_audit_unavailable` и один durable denial с reason
`audit_unavailable`. Ожидаемый конечный refusal -
`promotion_denial_audit_unconfirmed`. Ошибка до audit boundary не принимается.

Actual inference candidate использует qualification permit. Он не получает
фиктивный production assurance: controlled authorization bundle остаётся отдельным
subject. Поэтому это не доказательство разрешённого production release M10.

После удаления fault проверены прежние event ID/envelope digest, появившийся
receipt, совпадение producer outbox с collector и неизменность SQL/CAS. Worker
остановлен до finish, serving ownership возвращён штатным механизмом. Workflow
затем подтвердил остановку owned source SQL и удаление validated cluster с
проверкой отсутствия. **Post-cleanup offline replay завершился `success`**.

Первичные ML observations, context, reference, golden values и operator timeline
сохранены и перечитаны на runner. Security denial в этом компоненте пока хранится
как verified hash projection; полные подписанные security records всех sources
ещё необходимо объединить в общий M23 packet.
