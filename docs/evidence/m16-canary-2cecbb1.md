## Воспроизведение и границы результата

На шаге `traffic` прошли **100 Linux-тестов без пропусков**. Все 11 измеряемых модулей преодолели порог 95% отдельно для строк и ветвей. В модуле контрольного отката выполнены 367 из 370 операторов и 45 из 46 ветвей. Все последующие шаги, включая остановку исходного SQL и проверку доказательств, завершились успешно. [Журнал тестов](https://github.com/Abrakadabra124/trusted-mlsecops-platform/actions/runs/43536706837/job/132267369146).

Для повторения используйте Re-run all jobs у указанного запуска. Workflow начинает с чистого checkout и заново создаёт образ, ключи, SQL и входные материалы. Хеши выше идентифицируют первую попытку. Новый запуск оценивается по своим пакетам, метрикам и подписям. [Workflow](../../.github/workflows/canary-traffic.yml) · [Ранбук и разбор отказа](../operations/canary-rollout.md).

Нагрузка синтетическая, с одним вектором признаков. Для обученного кандидата действовало отдельное разрешение на проверку. Контроллер выполнил положительный откат на контрольных подписанных выпусках. Производственный допуск обученной модели требует полного assurance. Поле отчёта `release_ready` равно `false`. Для M17 требуется независимое восстановление из согласованной резервной копии, а общая приёмка M18 должна собрать обязательные результаты на одном зафиксированном кандидате.
